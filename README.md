# BCA Machine Learning Club Website

**Live:** [bcamlc.com](https://bcamlc.com)

Website for the Bergen County Academies Machine Learning Club. The club teaches students machine learning from the fundamentals up and runs [Project OmniBus](https://github.com/yash-korgaonkar/MLC-Competition), a reinforcement learning competition for high schoolers.

Static site (HTML, CSS, JavaScript) deployed on GitHub Pages with a custom domain.
